# Cosmosimulator 0.3.5

- Выбор системы стал компактнее: строки без внешних отступов, квадратный жёлтый ID вплотную к тёмной части с названием. Поиск, страницы и управление клавиатурой сохранены.
- Обычные подтверждения действий и ручного тика больше не попадают в историю уведомлений. Прибытия кораблей, завершение добычи и другие игровые события продолжают сохраняться.
- При обновлении из истории удаляются прежние записи «Действие выполнено» и «Тик выполнен»; остальные уведомления сохраняются. Фильтр также защищает от повторного добавления этих сообщений старым клиентом.
- Всплывающее уведомление уменьшено, стало прозрачнее и получило прямые углы. Значок результата и полоса исчезновения сохранены.
- Категории руководства пилота изначально свёрнуты. Поиск раскрывает совпадения; выбор статьи сохраняет раскрытую ветку.
- У корпораций-основателей убрано число участников. У корпораций игроков оно сохранено.

Проверки: тесты Go с PostgreSQL и детектором гонок, повторная миграция уведомлений без потери игровых событий, go vet, сценарии Chromium для выбора систем, руководства, корпораций и уведомлений. Windows x64 собран кросс-компиляцией; запуск службы под Windows в этой среде не проверялся.

Все предыдущие исполняемые файлы сохранены в `downloads`. Для обновления остановите службу и замените исполняемый файл, сохранив прежние параметры подключения.
