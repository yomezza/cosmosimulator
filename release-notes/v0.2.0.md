## Эдем / Edem

- Процедурная галактика из 1000 звёзд с постоянным seed, координатами, спектральными классами и стабильными ID.
- Граф гиперкоридоров: четыре связанных рукава по 245 систем и 20 изолированных звёзд. Между рукавами пути отсутствуют.
- Canvas-карта с масштабированием, перемещением и выбором звезды.
- Серверный планировщик кратчайшего маршрута по коридорам; отсутствующий путь отображается явно. Пересечение линий не означает пересадку.
- Галактика сохраняется в выбранной схеме PostgreSQL и сохраняется при перезапуске; создавать новую базу не нужно.
- Модуль локализации, русские и английские словари, переключатель в настройках. Выбор сохраняется в браузере.
- Windows x64 сборка и SHA256SUMS приложены; инструкция запуска в README.

Проверено: Go vet, интеграционные тесты PostgreSQL с race detector, детерминированность генерации и корректность путей, сохранение карты при повторной инициализации, браузерный сценарий с переключением языка и мобильным экраном.

Корабли и реальные перелёты пока не реализованы. Генератор поддерживает параметр количества систем; для гораздо больших миров понадобится оптимизация поиска соседей. Нативный запуск Windows-службы требует проверки на Windows.
