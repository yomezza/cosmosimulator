# Cosmosimulator 0.13.0

Завершён рефакторинг клиентского интерфейса M1–M14 с сохранением терминального оформления, игровых правил и HTTP API.

- Клиент разделён на native ES modules: инфраструктура, общие UI-компоненты и самостоятельные игровые разделы. Отдельно выделены вкладки рынка, Fleet, административные экраны, карты и планетарный renderer.
- Поздние ответы запросов больше не возвращают приватные данные в закрытое окно или сессию другого игрока. При потере admin-роли закрываются административные редакторы; logout очищает private DOM и buffers.
- Исправлены заголовок повторного подтверждения, положение раскрытого поиска после уменьшения экрана, состояние disabled после async-действия и сохранение HTTP status при не-JSON ошибке.
- Формы сохраняют введённые значения при обновлении данных без повторного исполнения игровых команд. Поиск получателя административной выдачи ресурсов использует правильный параметр `q`.
- Общие кнопки, popup, подсказки, окна, страницы и плитки ресурсов используют единственные реализации. Технические toast по-прежнему не засоряют журнал уведомлений.
- Сохранены ручные настройки веток/фильтров, отдельный трюм, порядок корпораций и личные названия станций. Названия применяются в представлении, исходный DTO не изменяется.
- Карта приостанавливает рисование, когда скрыта; публичные SVG/PNG имеют ограниченные кеши. Планетарные код и текстуры остаются лениво загружаемыми, география не перегенерируется.
- В `internal/platform/postgres` выделено подключение с точным `DB_SCHEMA` для будущей второй службы. Оно не создаёт игровой мир и не запускает миграции/симуляцию. Полноценная планетарная служба — следующая очередь.

Windows-служба по-прежнему запускается одним EXE без Node/npm. Новых игровых SQL-миграций нет. Предыдущие сборки сохранены в downloads.

Проверки: 45 browser/core/architecture PASS; 76 верхнеуровневых Go-тестов с одноразовой PostgreSQL PASS; 5 целевых race-тестов PASS; `go vet` и Windows amd64 build прошли. Полный race-прогон не прошёл из-за timeout и исчерпания контекстов в конкурентном планетарном сценарии; это ограничение отдельно описано в отчёте.
