# Cosmosimulator 0.20.0 · P2-6

Несколько пилотов видят друг друга на поверхности одного сектора: имена, появление/уход и плавно отображаемое серверное движение.

- Постоянный публичный UUID персонажа, начальный snapshot и изменения по WS v1. Приватные данные аккаунтов и другие сектора не раскрываются.
- Ограниченные очереди с заменой устаревших позиций, deadline медленному клиенту, Ping/Pong и resync.
- Автоматическое восстановление прежнего визита с backoff и пределом попыток. Заменённая вкладка сама не перехватывает управление обратно.
- Checkpoints с fencing/epoch/version CAS; проверено восстановление после отключения реального DB-соединения планетарного пула, пока cosmic продолжает tick.
- Панель администратора → **Статус служб**: отдельные карточки cosmic/planet, контурные теги, реальный readiness/проверка общей БД, технические сведения и автообновление 5s.
- Миграция marker=6 добавляет public_id и игровое имя в узкое session view; сцены и география сохраняются. Исправлен повторный migration runner: старый шаг не удаляет добавленные колонки view.

Обновить обе службы: остановить planet/cosmic, заменить EXE, сначала запустить cosmic для миграции, затем planet. Права/настройки от P2-4/5 сохраняются. [Инструкция и отчёт](../docs/planetary/P2-6/README.ru.md).

Проверки: две реальные браузерные сессии через gateway/WS, принудительный reconnect, takeover, истечение session, PostgreSQL recovery, race, backpressure, два отдельных процесса и две Windows x64 сборки. Нагрузка 50 игроков и переходы секторов остаются последующими этапами.
