# Cosmosimulator 0.17.0 · постоянные локальные сцены P2-3

Планетарная служба получила постоянную геометрию секторов, природный декор, коллизии и загрузку/выгрузку сцен. Это следующий серверный этап планетарного режима; персонажи, авторизованная 2D-высадка и движение ещё не включены.

- Локальная вода, высоты, реки и шестиугольные границы читаются из сохранённой общей карты.
- Площадки, spawn и пути к соседним секторам резервируются до размещения деревьев/камней.
- Геометрия и объекты сохраняются компактным snapshot в PostgreSQL с версиями и SHA256; перезапуск не меняет ландшафт/декор.
- Загрузки одного сектора объединяются, кеш ограничен, удерживаемая сцена не выгружается; пустые сектора не тикают.
- Источник, layout и действующий runtime fence проверяются перед записью и при повторной загрузке.
- Cosmic запрашивает подготовку удаления поверхности, planet освобождает и очищает свои сцены; удаление глобальной географии выполняется после повторного подтверждения.

**Обновление:** остановить обе службы, сохранить резервную копию, сначала запустить cosmic 0.17.0 для миграции схемы до 3, выдать planet дополнительные SELECT и INSERT/DELETE на локальные сцены, затем запустить planet 0.17.0. Настройки БД/схемы сохраняются. Новые параметры кеша необязательны.
