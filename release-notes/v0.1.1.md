### Настраиваемая схема PostgreSQL

- Добавлена переменная `DB_SCHEMA`: таблицы игры можно хранить в отдельной схеме уже существующей базы. Создавать отдельную базу не требуется.
- Выбранная схема используется всеми соединениями службы, без поиска таблиц в `public`.
- Отсутствующая схема создаётся при запуске, если у пользователя БД есть право `CREATE` на базу. Можно создать схему заранее и предоставить службе права на неё.
- Если `DB_SCHEMA` не задана, используется `public` для совместимости с v0.1.0.
- Имена схем безопасно экранируются; системные схемы и имена длиннее 63 байт отклоняются.
- Обновлены инструкции PowerShell и Windows-службы, а также Windows x64 исполняемый файл.

Пример настройки PowerShell:

```powershell
$env:DATABASE_URL = 'postgres://user:password@127.0.0.1:5432/existing_database?sslmode=disable'
$env:DB_SCHEMA = 'cosmosimulator'
.\cosmosimulator-windows-amd64.exe
```

Для установленной Windows-службы добавьте `DB_SCHEMA=cosmosimulator` в её переменные `Environment` в реестре и перезапустите службу (подробнее в README).

Смена схемы не переносит данные из предыдущей схемы. `sslmode=disable` в примере рассчитан на локальную БД.

Проверено: интеграция с PostgreSQL, изоляция двух схем в одной базе, несколько соединений пула, повторная инициализация, полный игровой API в выбранной схеме и `go test -race`. Windows-сборка получена кросс-компиляцией; нативный запуск Windows-службы по-прежнему требует проверки на Windows.
