Первая версия лёгкой браузерной космической экономической песочницы.

### Возможности
- Сервер на Go, PostgreSQL для аккаунтов, сессий и состояния мира.
- Встроенный веб-интерфейс без отдельной установки фронтенда.
- Регистрация, авторизация, выход; роли игрока и администратора.
- Добыча руды каждые 10 секунд, склад и продажа по фиксированной цене.
- Три автономные компании-бота с добычей и продажей ресурсов.
- Windows x64: запуск из консоли или как Windows-служба.

### Запуск
Скачайте `cosmosimulator-windows-amd64.exe`. Требуется PostgreSQL; задайте `DATABASE_URL` и запустите файл. По умолчанию веб-сервер слушает `127.0.0.1:8080`. Подробная инструкция, создание администратора и настройка службы приведены в README репозитория.

`SHA256SUMS` содержит контрольную сумму исполняемого файла. Путь `downloads/` в нём относится к расположению файла в репозитории.

### Проверки и ограничения
Пройдены интеграционные тесты с PostgreSQL, проверка гонок Go и браузерный сценарий регистрации, добычи, продажи и выхода, включая мобильную вёрстку. Windows x64 сборка проверена кросс-компиляцией; запуск на настоящей Windows и через Service Control Manager ещё не проверялся.

Это ранний прототип: рынок ордеров, строительство и восстановление пароля пока отсутствуют. Для публичного доступа необходим HTTPS.
