# Cosmosimulator 0.14.0

Разделён сам Go-сервер: в корне `internal/server` остались сборка приложения, маршруты и запуск. Игровая логика перенесена в самостоятельные пакеты.

- Выделены мир/галактики, каноническая география планеты, ресурсы, флот/навигация, добыча/исследования, экономика/логистика, рынки/верфи, корпорации, планировщик и колонизация.
- Отдельные Service получают явные зависимости. Игровые features не импортируют composition root и не получают весь прежний App.
- Сохранены общие транзакции, порядок блокировок и единственный космический tick. HTTP endpoints, JSON, SQL и правила экономики остались совместимыми.
- Подготовлены общие модели и инфраструктура для будущей планетарной службы. Canonical geography sampler можно использовать в локальной сцене без другой генерации берегов.
- Чистое подключение PostgreSQL отделено от cosmic migration/seed. Конструктор приложения не запускает симуляцию или bootstrap.
- Перенесены существующие интеграционные тесты, добавлены проверки архитектурных границ и совместимости генерации со старой версией.

Проверки: 79 Go-тестов с одноразовой PostgreSQL, 7 целевых race-сценариев, 45 браузерных проверок и go vet прошли. Генерация и sampler сверены с эталонами 0.13.0.

Новых SQL-миграций и перегенерации существующих планет нет. Windows поставляется одним EXE; старые сборки сохранены.
