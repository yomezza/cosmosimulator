# Cosmosimulator 0.15.0 · P2-1

Добавлена основа отдельного планетарного сервера: второй Windows x64 EXE `cosmosimulator-planet`, собственный HTTP-порт и имя службы `CosmosimulatorPlanet`.

- Подключение к существующим DATABASE_URL/DB_SCHEMA через общий PostgreSQL-пакет, без повторного bootstrap, создания галактики или мирового тика.
- Endpoints live/ready, проверка совместимости схемы и отдельный JSON-журнал.
- Единственный владелец планетарного runtime через PostgreSQL lease и монотонное поколение fence; отказ просроченному/второму процессу.
- Корректная остановка, освобождение lease и восстановление после аварийного завершения.
- Минимальная аддитивная миграция schema150.sql выполняется только космическим сервером: две инфраструктурные таблицы, без изменения колоний, визитов, кораблей или экономики.
- Настройка ограниченной роли БД и независимой службы Windows описана отдельно.

Это P2-1: **2D-сцены, персонажи, движение и WebSocket-высадка ещё не реализованы**. Даже ready=200 возвращает gameplay_ready=false; WS route отвечает 503 и не принимает билеты. Следующий этап — территории и посадочные площадки.

Сначала обновить и запустить космический EXE, чтобы применить миграцию, затем запускать planet на другом порту. Космический процесс продолжает работать без второго сервера. Старые сборки сохранены; в этом релизе два версионных EXE.
