# Cosmosimulator 0.14.1

Исправлена ложная ошибка при переносе ресурсов со склада станции в трюм: операция на сервере завершалась, а браузер вызывал удалённую `window.refresh`. Теперь обновляются настоящие снимки трюма и складов.

- Обновление данных не прерывает перетаскивание груза; проверены переносы в обе стороны и нескольких ресурсов сразу.
- Планировщик подхватывает купленные/переименованные корабли без повторного открытия и дожидается обновления очереди после команды.
- Отмена редактирования пользователя и настроек игрового процесса возвращает серверные значения.
- Форма доставки выбирает существующую станцию вместо жёстко заданного порта.
- Переход из уведомления выбирает нужную систему даже при первом открытии карты.
- Усилена обработка поздних ответов карты и логистики после выхода/смены аккаунта. Административные окна колонизации закрываются при потере прав.
- Исправлен отсчёт восстановления квот в карточках объектов.
- Тестовая среда больше не восстанавливает удалённые globals; добавлены архитектурные проверки и сценарий настоящего терминала с Go API/PostgreSQL в CI.

Проверки: 57 UI PASS, 79 Go PASS с PostgreSQL, 7 целевых race PASS, отдельный real-browser сценарий PASS, go vet PASS.

Новых SQL-миграций и перегенерации нет. Обновление: остановить службу, заменить EXE, запустить и перезагрузить страницу. Старые сборки сохранены в downloads.

[Подробный отчёт: проблемы, решения и охват проверки](https://github.com/yomezza/cosmosimulator/blob/v0.14.1/docs/qa/terminal-0.14.1.ru.md).
