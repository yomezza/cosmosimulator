# Cosmosimulator 0.14.4

В предложениях игроков отображается статус идеи:

- «Одобрено»: зелёная рамка.
- «Не одобрено»: красная рамка.
- «На рассмотрении»: оранжевая рамка.

У тега прозрачный фон, нейтральный текст по центру. Статус виден в личном списке, административном списке и карточке идеи.

Администратор выбирает статус в карточке предложения и нажимает «Сохранить статус». Сервер проверяет права и допустимое значение; игрок не может назначить статус своей идее. Изменение сохраняется в PostgreSQL. У открытого личного списка сведения обновляются при очередном обновлении данных; при открытии загружается актуальный статус.

Миграция schema144.sql добавляет поле status к player_ideas. Все существующие и новые предложения по умолчанию находятся на рассмотрении; содержимое идей сохраняется. Миграция выполняется при запуске космической службы существующим механизмом под блокировкой.

Адресные проверки: браузерный сценарий оформления и сохранения статуса; Go/PostgreSQL — права, допустимые статусы, сохранение и получение автором, прежняя отправка/повторы, каталоги перевода. Общие наборы локально повторно не запускались.
