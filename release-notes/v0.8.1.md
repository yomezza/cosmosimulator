# Cosmosimulator 0.8.1

Исправления подтверждённых экономических и серверных проблем, закрытая генерация разведданных и компактный интерфейс терминала.

## Что было исправлено

| Проблема | Решение | Проверка |
|---|---|---|
| При переходе остатка 10 → 9 цена росла на 5 CR при торговой разнице 2 CR. Покупка и обратная продажа давали +3 CR. | Убран скачок от малого остатка. Региональные и системные цены, комиссии и конечные кошельки сохранены. | Десять циклов теперь расходуют 20 CR, восстанавливают запас и сохраняют общую сумму денег игрока и станции. |
| Каждая покупка и продажа выдавала репутацию, позволяя накручивать её одними и теми же товарами. | Обычные сделки больше не выдают репутацию. Завершённые доставки продолжают её повышать; уже имеющиеся очки сохранены. | Повторные обратные сделки не увеличивают репутацию. |
| Публичные seed, веса ресурсов и генерация по известным ID позволяли вычислять скрытые объекты. | Публичный API карты больше не отдаёт seed и внутренние настройки. Скрытая генерация использует постоянный случайный серверный секрет и независимые HMAC-потоки для планет и ресурсов каждого объекта. Секреты и внутренние выборки исключены из публичных ответов. | Проверены отсутствие приватных полей во всех трёх API карты/системы/экспедиции, различие миров при одинаковых публичных параметрах и несоответствие старому прогнозу по ID. |
| Запрос экспедиции захватывал общую игровую блокировку до чтения JSON. Медленная отправка задерживала действия других игроков и тики. | Полный JSON объёмом до 4 KiB читается и проверяется до вызова обработчика. Для запросов API добавлен контекстный предел 12 секунд на ожидание БД и обработку. HTTP-тайм-аут чтения сохранён. | Пока один запрос не закончил отправку, действие другого аккаунта и обработка тика завершаются. |
| Все пользователи за reverse proxy попадали в один лимит входа по адресу прокси. | Добавлен явный список `TRUSTED_PROXIES` и разбор цепочки реальных клиентских адресов. Лимиты входа и регистрации разделены. Заголовки от недоверенных клиентов игнорируются. | Один клиент за доверенным прокси исчерпывает свой лимит, другой продолжает входить; подмена адреса прямым клиентом и поддельный левый адрес в цепочке не принимаются. Проверен IPv6. |

Для прокси требуется настройка доверия: например, `TRUSTED_PROXIES=127.0.0.1/32,::1/128` при локальном reverse proxy. Укажите реальные адреса своего прокси; он должен записывать или дописывать справа фактический адрес клиента в `X-Forwarded-For`. Без этой настройки служба безопасно использует непосредственный адрес соединения, общий для пользователей такого прокси. Правила сложности пароля не добавлялись.

Дополнительно проверены отказ обычному игроку во всех административных изменениях, запрет выбора/изъятия груза чужого корабля, подмена поля баланса, отрицательные и завышенные количества, некорректные и слишком большие JSON. Существующие проверки повторных и конкурентных переносов, вместимости, резервов добычи, корпоративных полномочий и атомарности финансов входят в полный прогон.

## Сохранение мира

Секрет создаётся один раз и хранится в PostgreSQL вместе с миром. Перезапуск не меняет секрет, планеты или месторождения. Создание, расширение галактик и их предпросмотр используют тот же закрытый механизм для нового содержимого.

При обновлении сохраняются объекты и залежи систем, которые уже исследовались, наблюдались, содержат корабли, квоты добычи или объектные задания; учебные системы 1 и 5 также сохранены. Для сохранённых залежей приватные выборки поддерживают дальнейшее изменение распространённости ресурсов администратором.

В ранее не наблюдавшихся системах скрытые планеты и месторождения переводятся на новую генерацию. ID/имена/координаты систем, классы звёзд, гиперкоридоры, станции, аккаунты, деньги, грузы и текущие задачи сохраняются. Уже раскрытые в прежней версии сведения невозможно сделать неизвестными задним числом; сохранённые наблюдаемые объекты не пересоздаются.

## Интерфейс

- Слева отдельная маленькая кнопка сворачивания, подпись **«Модули»** по центру, разделительная линия и тонкие прямоугольные кнопки разделов высотой **28 px**. Состояние панели сохраняется, подсказка и `aria-expanded` соответствуют её состоянию.
- Обычные текстовые действия получили общий стиль тонких прямоугольников. Кнопки рынка, вкладки, поля количества и отступы таблиц стали компактнее. Плитки ресурсов, флаги и составные карточки сохранили своё назначение.
- Выбранные значения в поиске станций рынка и систем правой панели карты используют общую сетку: жёлтый квадрат без скруглений, текст и отдельная область стрелки. Квадрат больше не сдвигается из-за стилей панели. Повторное нажатие закрывает список.
- Добавлено соответствие голограммы и цветного тега для фактического типа планеты «Вулканическая».
- Русский/английский интерфейс и свёрнутая панель на небольших экранах поддержаны.

## Проверка и установка

Проверки: Go/PostgreSQL с `-race`, `go vet`, регрессии ранее найденных обходов и Chromium для панели, размеров кнопок, выбранных значений и поиска на рынке/карте. Контрольные суммы старых Windows EXE сохраняются.

Перед обновлением остановите службу, сохраните резервную копию игровой схемы и замените EXE. После запуска обновите страницу игры. Для отката используйте соответствующую резервную копию: старые версии не сохраняют новые приватные поля мира. Windows x64 проверен кросс-компиляцией; запуск Windows-службы в Linux-среде не проверялся.
