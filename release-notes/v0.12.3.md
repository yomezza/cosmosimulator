# Cosmosimulator 0.12.3

- Рядом с названием каждого корабля в планировщике показан счётчик текущих заданий: в очереди, выполняющихся и приостановленных. Завершённые и отменённые задания не учитываются; корабль без заданий показывает 0.
- Ветки кораблей по умолчанию свёрнуты. Ручное раскрытие/сворачивание сохраняется отдельно для игрока и корабля, включая перезагрузку страницы и обновления данных.
- При первом открытии после обновления старое автоматическое раскрытие из 0.12.2 сбрасывается: используется новая версия настройки веток. Последующие действия игрока запоминаются. Состояние вложенных карточек задач сохраняется как прежде.

Серверное выполнение задач и база данных не изменяются.

Проверки: `go test ./... -count=1` и `go vet ./...` прошли (Go-тесты с TEST_DATABASE_URL пропущены). Chromium на отдельной тестовой схеме PostgreSQL подтвердил счётчики 0/2/1 по трём кораблям, обновление после отмены задачи, начальное сворачивание при наличии старых настроек, сохранение раскрытия/сворачивания после перерисовки и перезагрузки, английские подписи и отсутствие ошибок JavaScript.
