# Cosmosimulator · 0.7.0

Лёгкая браузерная космическая экономическая песочница: Go + PostgreSQL, встроенные HTML/CSS/JavaScript и SVG. Один Windows x64 `.exe` подключается к существующей базе и обслуживает игру по HTTP. npm для запуска и сборки не нужен.

## Запуск в Windows

Нужен PostgreSQL 17 или совместимая версия. **Отдельную базу создавать не обязательно**: `DATABASE_URL` указывает существующую базу, `DB_SCHEMA` — отдельную игровую схему. По умолчанию используется `public`. Отсутствующая схема создаётся при наличии права `CREATE` на базу; можно создать её заранее:

```sql
CREATE SCHEMA cosmosimulator AUTHORIZATION cosmos;
```

Роль службы должна иметь права на игровую схему, её таблицы и последовательности. Схема не должна содержать одноимённые таблицы другого приложения.

```powershell
$env:DATABASE_URL = 'postgres://cosmos:YOUR_URL_ENCODED_PASSWORD@127.0.0.1:5432/existing_database?sslmode=disable'
$env:DB_SCHEMA = 'cosmosimulator'
$env:HTTP_ADDR = '127.0.0.1:8080'
# Только для первоначального создания администратора:
$env:ADMIN_USERNAME = 'operator'
$env:ADMIN_PASSWORD = 'YOUR_PASSWORD'
.\downloads\cosmosimulator-v0.7.0-windows-amd64.exe
```

Откройте `http://localhost:8080`. Остановка — Ctrl+C. После создания администратора удалите `ADMIN_USERNAME` и `ADMIN_PASSWORD`; bootstrap не меняет существующие пароли и не повышает игрока до администратора. `.env.example` — справочник, `.env` автоматически не читается.

Пароль — непустая строка до 72 байт UTF-8, без требований к сложности. Имена игроков: 3–24 латинских буквы, цифры, `_` и `-`. Пароли хешируются bcrypt, сессии хранятся в виде хешей токенов; cookies HttpOnly/SameSite. Сервер проверяет роли, владение кораблями и имуществом, Origin запросов и ограничивает попытки входа.

`DB_SCHEMA` — одно точное имя до 63 байт, не список схем. Имена с пробелами и кавычками экранируются. Системные схемы и специальное имя `$user` запрещены. Все соединения пула используют эту схему без fallback в `public`. Смена схемы не переносит данные.

Для доступа извне используйте HTTPS reverse proxy, `PUBLIC_ORIGIN=https://your-domain`, `COOKIE_SECURE=true` и подходящий `HTTP_ADDR`. Для удалённой PostgreSQL используйте проверяемый TLS. Не коммитьте пароли и строки подключения.

## Windows-служба и обновление

Исполняемый файл поддерживает Service Control Manager. После проверки консольного запуска скопируйте выбранную сборку в `C:\Cosmosimulator\cosmosimulator.exe`. В PowerShell администратора:

```powershell
sc.exe create Cosmosimulator binPath= 'C:\Cosmosimulator\cosmosimulator.exe' start= auto
New-ItemProperty -Path 'HKLM:\SYSTEM\CurrentControlSet\Services\Cosmosimulator' -Name Environment -PropertyType MultiString -Value @('DATABASE_URL=postgres://cosmos:YOUR_URL_ENCODED_PASSWORD@127.0.0.1:5432/existing_database?sslmode=disable','DB_SCHEMA=cosmosimulator','HTTP_ADDR=127.0.0.1:8080') -Force
sc.exe start Cosmosimulator
sc.exe query Cosmosimulator
```

Окружение службы отличается от окружения PowerShell. Перед обновлением остановите службу, сохраните резервную копию схемы и замените `.exe`. Запускайте одну версию сервера на одной схеме. Миграция 0.3.3 меняет ключ кораблей и привязывает задания добычи к конкретным кораблям; **0.3.2 нельзя запускать на обновлённой схеме**. Для возврата нужна резервная копия схемы 0.3.2.

Миграции выполняются транзакционно под advisory lock. Сохраняются аккаунты, кредиты, грузы, ID кораблей и систем, исследования, брони и задания добычи. Windows-сборка проверяется кросс-компиляцией; нативный SCM в облачной Linux-среде не проверялся.

## Рабочий терминал

Слева — сворачиваемая панель модулей. Вверху — переключатель открытых окон, уведомления, профиль и меню администратора. Уровень/опыт находятся рядом с именем на главной; корпорация показана цветным тегом. Статус сервера «Иггдрасиль», число активных за последние пять минут игроков и ботов доступны в подсказке футера.

При открытии «Корабля» слева появляется отдельная голограмма выбранного корпуса. Трюм открывается справа по кнопке. Голограмма, окно корабля и трюм могут перемещаться вместе; боковые окна можно отделять, закреплять и менять в размере. При обновлении данных анимация не перезапускается. У каждого корабля свой каркас с зелёным свечением, световыми импульсами и оборотом за 16 секунд; SVG и область голограммы прозрачны. Модели также используются в верфях и руководстве.

В истории уведомлений сохраняются игровые события: прибытие, завершение добычи/исследования/доставки, приглашения и завершение проектов. Обычные подтверждения действий и ручного тика показываются только компактным полупрозрачным сообщением. При обновлении старые записи «Действие выполнено» и «Тик выполнен» удаляются из истории. Категории руководства пилота свёрнуты по умолчанию; поиск раскрывает совпадения.

Окна перемещаются за заголовок, меняют размер, закрепляются и разворачиваются кнопкой или двойным нажатием заголовка. Закрепление запрещает перемещение и изменение размера. Маленькое окно предлагает увеличить его. Escape закрывает верхнее используемое окно; контекстное меню и поиск сначала закрываются отдельно. Расположение хранится в браузере.

«Трюм» — самостоятельное окно рядом с кораблём. Его можно связать с кораблём по перемещению и затем отделить. Груз представлен плитками с кодом и количеством, фильтрами, сортировкой, подробными подсказками и действиями ЛКМ/ПКМ.

Большие ответы API сжимаются gzip при поддержке клиента; исходный каталог станций заполняется один раз на загруженную вселенную. Фирменные выпадающие списки поддерживают поиск, клавиатуру и страницы по десять строк. Список систем ищется по названию/ID, показывает ID в жёлтом квадрате, известность и присутствие своих кораблей. Доступны обычная/компактная плотность, русский и английский языки. Словари: `internal/server/web/ru.json` и `en.json`.

## Галактика, навигация и разведданные

Эдем содержит **3000 процедурно созданных звёзд**, четыре рукава с редкими межрукавными связями и изолированные системы. Миграция сохраняет ID, имена, планеты, корабли и имущество; старые координаты Эдема масштабируются втрое. Сеть коридоров становится разреженной, действующие маршруты и два учебных коридора сохраняются. Системы используют обозначения ED/KE/AX/NX и полноценные имена; миграция 0.3.4 сохраняет ID и пользовательские названия. Перелёт возможен только по найденному пути; пересечение линий не является соединением. Базовый расход — 2 топлива и 5 секунд на переход. Поддержаны маршруты с промежуточными точками, резерв топлива, закладки и личные заметки о системах/объектах.

В центре — чёрная дыра с шестью ближайшими системами доступа. Порты корпораций-основателей есть в том числе в этих системах. Их названия пока **«Корпорация-основатель 01»** и **«Корпорация-основатель 02»**; постоянный лор не задан. Внутренние ключи основателей отделены от будущих пользовательских названий и тегов.

Контекстное меню системы предлагает маршрут, локальную карту и исследование. Карту неизвестной системы можно открыть: видна звезда и собственные корабли. Объекты раскрываются по очереди при сканировании; корпоративные порты уже известны своей корпорации. Публичные станции доступны для стыковки по данным рынка, без раскрытия планет. Общая энциклопедия не раскрывает конкретные неизвестные месторождения. Собственные корабли отображаются на обеих картах, включая движение и орбиту. Колесо управляет масштабом, зажатая ЛКМ — перемещением.

Экспедиция предварительно показывает путь, число объектов, время, топливо, цену и предупреждение об обратном пути. Первое собственное исследование стоит 10 CR, даёт 10 XP по завершении и сканирует каждый объект по одной секунде по умолчанию. Можно приостановить/продолжить с сохранением прогресса; повторная оплата не берётся. Новые сроки сохраняются в БД и обрабатываются службой, а не только браузером.

Разведданные продаются **игроками на станциях**, без начального NPC-ассортимента. Пакет фиксирует лично исследованные продавцом системы одного региона. Покупатель видит покрытие, дату предложения и число новых систем; полностью известные данные повторно не оплачиваются. Купленное знание открывает карту, но не выдаёт награду за собственное сканирование и не включается в пакеты личных исследований для перепродажи. Рыночные цены и квоты обновляются отдельно от постоянных сведений об объектах.

Модель планет приближённая: 3–7 планет на звезду, масса, гравитация, атмосфера и равновесная температура `278 × L^0.25 / sqrt(AU)` без парникового эффекта. Орбиты на карте схематические. Садовый мир не гарантирует пригодную для дыхания атмосферу.

**Астерион** (прежнее имя Edem-II) состоит из трёх концентрических звёздных поясов. Edem остаётся спиральной. Принадлежность системы определяется ключом галактики, независимо от диапазона её ID: расширение Edem не смешивает её с уже открытым Астерионом. На карте полупрозрачные круги показывают небольшие колонии корпораций-основателей вокруг их станций. Вне этих кругов системы нейтральны. Цвет изученной звезды соответствует её спектральному классу. Подсказка при наведении показывает сводку и владельца, сведения об объектах появляются только после их исследования.

Администратор может выбрать «Телепортироваться» в меню системы на галактической карте: выбранный корабль переносится к точке входа без затрат топлива, в том числе между открытыми галактиками. Движение сбрасывается, исследование приостанавливается с сохранением прогресса. Активную добычу или доставку нужно завершить заранее. Право проверяется сервером, действие записывается в журнал; неизвестные объекты автоматически не раскрываются.

## Стаж, кошелёк и автоматизация

Лимит каждого личного, корпоративного и станционного кошелька — **500 000 000 000 CR**. Суммы хранятся как PostgreSQL BIGINT и Go int64. Операция, превышающая лимит получателя, отклоняется целиком: деньги и товар не пропадают. Автоматический возврат брони или оплата доставки при полном кошельке остаются в ожидании и повторяются после освобождения места. Старые средства не обрезаются при миграции.

«Уровень игрока» переименован в **стаж игрока**. Развитие продолжается выше 100; техническая граница текущего счётчика — 1 000 000. Правила XP и стоимость повышения сохраняются. Покупка Пилигрима и Скитальца требует стажа 6; Горна, Ковчега, Гермеса, Веспера и Ириды — 10; Астры, Тигля, Атласа и Зефира — 15; Аргуса, Титана, Левиафана и Молнии — 20. Уже приобретённые корабли продолжают работать независимо от стажа. Корабли можно переименовывать (1–40 символов); ID базы данных не показывается рядом с названием.

В «Планировщике задач» доступны **добыча** и **перевозка между личными складами станций**. Очередь хранится в PostgreSQL и обрабатывается службой каждую секунду при закрытом браузере. На корабле выполняется одна задача; разные корабли работают независимо. До 20 незавершённых задач на игрока, до 100 000 единиц в задаче. Состояние, прогресс, загруженная партия, полёт и текущий цикл добычи переживают перезапуск.

- Добыча требует исследованного объекта и подходящего добытчика. Использует обычные общие квоты и завершается по игровым фазам. Можно оставить груз в трюме или выбрать личный склад той же системы: при заполнении трюма корабль выгружает добытый этой задачей ресурс и возвращается. Другой груз сохраняется.
- Перевозка забирает реальный товар со склада отправления, летит по гиперкоридорам, стыкуется и выгружает его на склад назначения. Большая партия перевозится несколькими рейсами.
- Топливо и манёвры оплачиваются обычным расходом. При необходимости автоматическая заправка использует Агни из трюма. Если маршрут превышает вместимость бака, топлива/товара/места недостаточно или квота исчерпана, задача ставится на паузу с объяснением. Покупать топливо автоматически планировщик пока не умеет.
- Пауза и отмена останавливают дальнейшие шаги. Уже начатый полёт или цикл добычи завершается, физический груз остаётся на корабле. Завершение и остановка с причиной приходят в уведомления. Для ручного управления кораблём приостановите его активную задачу.

Администратор может выдать ресурс в конкретный трюм, личный склад на действующей станции или склад корпорации. Выдача в трюм учитывает вместимость и зарезервированное место под добычу. Все выдачи записываются в журнал администратора.

Администратор создаёт галактики через **предпросмотр → применение**. Формы: спиральная, кольцевая, эллиптическая, нерегулярная; можно задать имя, seed, число систем, гиперкоридоры, станции и распространённость ресурсов. От 50 до 10 000 систем на новую галактику, до 24 галактик и 50 000 систем в мире. У каждой открытой галактики своя центральная чёрная дыра; через ближайшие системы можно выбрать другую открытую галактику. Старые IDs, имущество и текущие полёты сохраняются.

Поиск систем и станций использует имена; поиск по техническому номеру тоже работает. Избранное справа сохраняется на сервере для аккаунта. Существующие заметки при добавлении в избранное сохраняются. Легенда показывает образцы линий и символов, селекторы используют сплошной фон. Основатели показываются первыми в корпорациях, затем академия, разделитель и корпорации игроков.

Базовая цена начинается со 100 000 CR и рассчитывается от характеристик «Пилигрима»: +1000 CR за единицу трюма, +2000 CR за единицу бака, +90 000 CR за единицу бонуса добычи. Доплата за скорость — `600000 / секунд перехода − 120000`, за экономичность — `120000 / расход − 60000`. Округление вверх до 5000 CR; итог не ниже 100 000 CR. Длина показывает размер корпуса, сама по себе цену не увеличивает.

Раздел «Верфи» доступен слева, в рынке и из карточки корабля. Есть поиск по системе/модели, фильтры назначения и корпуса, страницы и маршрут к системе верфи. На новой верфи только 3–4 модели, после расширения старого ассортимента — до 5; собственные конечные запасы и наценка 0–10% от базовой (Пилигрим — ровно 100 000 CR). Купить можно только после стыковки с конкретной верфью. Купленный корабль появляется там же и не заменяет активный; его можно выбрать в окне корабля. Производство и пополнение верфей игроками остаются отложенными.

При переходе на 0.6.0 прежние предложения однократно переоцениваются, на верфи поступает ограниченная партия новых моделей. Проданные старые корпуса не восстанавливаются; перезапуск не пополняет запасы и не меняет цены заново. Уже купленные корабли, трюмы и топливо сохраняются. Улучшенные модели крупнее предшественников; это видно в масштабе голограмм и длине корпуса.


Манёвр к объекту занимает 5 секунд и 1 топлива. Добыча требует исследования и присутствия у объекта; торговля — стыковки. 1 Агни восстанавливает до 5 топлива. Буксировка к ближайшему достижимому порту занимает 30 секунд, стоит 100 CR по умолчанию и восстанавливает минимум 10 топлива; если в компоненте карты вообще нет порта, услуга недоступна.

Новые корабли продаются с полным баком. Заправка расходует Агни из трюма выбранного корабля: 1 единица даёт до 5 топлива. Кнопка и подсказка различают полный бак, движение и отсутствие Агни; запас топлива в трюме виден в панели корабля. Действия покупки и заправки проверяют ID активного корабля, чтобы смена корабля в другой вкладке не направила действие в другой трюм.

Базовый добытчик даёт до 3 единиц за цикл. В порту за 250 CR можно установить рудный, ледовый или газовый добытчик: 4–6 единиц в зависимости от качества Q1–Q5 и концентрации. Тип оборудования ограничивает материалы. Улучшение не отменяет общую квоту. Результат сохраняемого задания доставляется в трюм на следующей фазе; места резервируются заранее. Отмена возвращает квоту только в исходный период.

Общая квота объекта — **5000 на всех игроков и материалы**, отдельный редкий ресурс — **300–600 в пределах общей квоты**. Восстановление — **5 реальных часов**, независимо от скорости звёздной даты. Изменения лимитов действуют для новых периодов; администратор может явно восстановить квоты сразу. Конкурентные операции блокируют строки и не дают отрицательных остатков.

Названия ресурсов сохранены, описания написаны по игровому лору. Железо, углерод, вода и кремний встречаются чаще; Орихалк, Ваджра и Амброзия редки. Распределение зависит от системы/объекта. Учебное производство отдельно даёт 1 ORE за фазу и продажу по 5 CR; оно остаётся начальным источником валюты.

## Торговля, склады и перевозки

Восемь профилей торговли: торговый узел, металлургия, материалы, промышленность, продукты, агрокомплекс, химический комплекс, энергетика. Каждая станция торгует только частью ресурсов своего профиля: железо есть не у всех металлургических портов. Ассортимент сохраняется и не меняется при перезапуске. Добавлены Адамант, Электрум, Нектар и Сома — готовые партии для соответствующих профилей; их производство пока не вводится.

Каждый порт имеет **собственные** конечные запасы и кошелёк; личные и корпоративные склады также привязаны к **конкретной станции**. У основателя 02 тариф 2% с округлением вверх до CR, включённый в котировку; репутация 20 его отменяет. Сделки и доставки повышают репутацию. Это стартовые параметры для последующего баланса.

Местная покупка поступает в трюм. Глобальная бронь оплачивается в escrow и ждёт получения на конкретной станции продавца. Срок — 72 часа по умолчанию, комиссия хранения — 0 CR, отмена/истечение возвращает полную оплату и товар на рынок. Повторное получение не выдаёт груз повторно. Интерфейс проверяет изменение показанной цены до сделки.

Игроки выставляют товар с личного склада по фиксированной цене. Покупка у игрока переводит средства продавцу, товар остаётся на складе покупателя **на той же станции**, пока его не заберут или не перевезут. Остаток заявки резервируется транзакционно.

Заказ доставки содержит груз в пределах вместимости выбранного корабля, станции, награду, обеспечение и срок 1–168 часов. Отправитель резервирует товар и награду. Бот перевозит за `30 + 5 × число систем пути` секунд; награду получает существующий бот. Другой игрок принимает груз на подходящий корабль и вносит обеспечение не меньше базовой стоимости груза. Завершение проверяет стыковку и груз. При просрочке открытого заказа товар/награда возвращаются; при просрочке принятого игроком заказа отправитель получает награду и обеспечение. Это логистические договоры; общая система квестов отложена.

История финансов фиксирует изменения баланса и причины. Торговые боты расходуют конечные деньги и товары.

## Корпорации, проекты и портал

Новые игроки вступают в «Академию Эдема». Своя корпорация стоит **1 000 000 CR** по умолчанию; цена меняется администратором. Полное имя — 3–60 символов, уникальный тег — 3–4 буквы/цифры, цвет и флаг. Доступны плитки флагов и конструктор фона, полосы и символа.

Владелец создаёт до **7 дополнительных ролей**, задаёт им названия и полномочия финансов, участников, проектов и выдачи со склада. Владелец и первоначальный участник не входят в лимит. Права проверяются сервером. Есть заявки/приглашения, общий кошелёк, финансовый журнал и передача владения. Вступление в Академию открыто; другие игроки принимаются по заявке или приглашению.

Совместные проекты требуют ресурсов с личных складов: корпоративный склад — 100 железа и 50 кремния; порт/станция — 200 железа, 100 кремния и 20 Орихалка. Учитываются вклады. Построенный порт появляется на карте и принимает корабли; склад работает только на станции проекта. При роспуске нужно закрыть активные проекты и освободить склады; остаток денег получает владелец, построенные порты переходят основателю 01.

Портал активируется общими взносами **1 000 000 CR**. После активации создаётся дополнительная галактика **Астерион**, 1000 звёзд с отдельными ID и новыми регионами. Переход из Эдема доступен из шести систем у чёрной дыры, обратный — из входной системы Астериона. Исходные системы и данные игроков не заменяются. Эти численные параметры — начальная реализация, а не окончательный баланс/лор.

## Уведомления, руководство и администратор

Уведомления сохраняются в БД: прибытия, исследования, добыча, доставки, проекты и сообщения действий. Счётчик `99+` при числе больше 100, группировка, удаление одного/выбранных/всех. Всплывающие сообщения показывают результат и полосу времени. Из события можно открыть связанный модуль. Руководство пилота содержит поиск по имени/коду/описанию, общие статьи об объектах и ресурсах, связанные материалы.

Верхнее меню администратора содержит ручную фазу, пользователей, игровой процесс, галактики, журнал изменений и бенчмарк. Ручная фаза выполняет один тик, сохраняет меню открытым и сообщает результат уведомлением. Пользователи — максимум 10 на страницу с поиском, отдельное окно редактирования. Смена пароля/роли завершает сессии; нельзя понизить себя или последнего администратора. Доходы в истории финансов показаны зелёным со знаком «+», расходы — красным со знаком «−». Административные действия журналируются без паролей. «Журнал изменений» — отдельное окно с поиском, фильтром действий, страницами по 20 записей, сравнением параметров и полными данными записи. Журнал событий удалён из профиля игрока; его API доступен только администраторам.

«Галактики» показывает список миров и позволяет переименовывать и расширять открытые галактики до 10 000 систем. Настраиваются дополнительные коридоры, межрукавные связи, максимальная длина новых коридоров, доля систем со станциями, максимум портов и распространённость каждого добываемого ресурса (0–300%). Частота генерации станций плавно падает с расстоянием от центра до нуля на окраинах. Значение 18% по умолчанию — частота у центра; в среднем по галактике станций значительно меньше. В базовом Edem 2560 из 3000 систем нейтральны, 36 небольших колоний занимают суммарно около 4,4% площади карты. Стартовые порты, порты у чёрной дыры, станции с кораблями, имуществом, заказами и перевозками сохраняются даже при снижении доли станций. Неиспользуемые порты архивируются со всеми запасами; при возвращении в распределение их запасы не сбрасываются. Защищённые публичные порты вне колоний становятся нейтральными, сохраняя товары и обязательства. Станции игроков не меняют владельца.

Изменения применяются только после предпросмотра: карта, количество систем/коридоров/станций и распределение ресурсов до/после. Предпросмотр ничего не записывает в мир. Устаревший предпросмотр нельзя применить повторно. Существующие системы не удаляются; текущие перелёты и пути для очереди сохраняются, избыточный резерв топлива освобождается. Изменение карты автоматически приходит другим открытым клиентам.

Хронология Эдема: `ЭД 0001·042·318`, 360 дней в году, 1000 импульсов в дне. По умолчанию фаза раз в 10 секунд, +1 импульс. Настраиваются фазы, дата, лимиты/периоды, сканирование, цена корпорации, эвакуация и хранение брони.

Бенчмарк: 1–500 виртуальных игроков, 5–300 секунд, сценарии смешанных запросов, последней квоты, последнего товара и бронирования/получения. Реальные HTTP API и PostgreSQL работают с одноразовой схемой той же базы, без расходования имущества настоящих игроков; роли БД нужно право создания схем. Это технический минимальный стенд, без отложенного настраиваемого генератора миров. Можно остановить запуск; отчёты хранят задержки p50/p95/p99, RPS, ошибки, ожидания пула и проверки целостности. Ожидаемые HTTP 409 при конкуренции учитываются отдельно. После запуска схема удаляется.

## Разработка и выпуск

Go 1.26+, PostgreSQL. Обычные проверки:

```sh
go mod download
go vet ./...
go test ./...
TEST_DATABASE_URL='postgres://cosmos:password@127.0.0.1:5432/cosmosimulator_test?sslmode=disable' go test -race -count=1 -v ./...
```

Без `TEST_DATABASE_URL` интеграционные тесты пропускаются. Для них нужна одноразовая база с суффиксом `_test` и создание схем. Проверяются миграция из 0.3.2, изоляция схем, авторизация/права, флот, асинхронная разведка, квоты, конкурентная торговля, склады/доставки, корпорации, портал и отсутствие повторных начислений.

```sh
CGO_ENABLED=0 GOOS=windows GOARCH=amd64 go build -trimpath -ldflags='-s -w' -o downloads/cosmosimulator-v0.7.0-windows-amd64.exe ./cmd/cosmosimulator
sha256sum downloads/*.exe > downloads/SHA256SUMS
```

Все предыдущие версионные `.exe` сохраняются. Тег `vX.Y.Z` запускает GitHub Actions, прикладывающий соответствующий файл, контрольные суммы и `release-notes/vX.Y.Z.md`. Опубликованные сборки не перезаписываются.

API управления галактиками: `GET /api/admin/galaxies`, `POST /api/admin/galaxies/preview`, `POST /api/admin/galaxies/apply`; журнал администратора: `GET /api/admin/changes?page=1&search=...&action=...`. Только роль `admin`; старый `/api/events` также больше не доступен игрокам. Общая система квестов, судостроение, аномалии, косметика кораблей, звук и публичная хроника остаются отложенными; экспорт карты отклонён.
