# Графика глобальной поверхности: оценка и ТЗ

Дата: 29 октября 2026. Новые изображения в рамках 0.12.4 **не генерировались**, оригинальные PNG не изменялись.

## Что есть

Исследованы ресурсы Git-репозитория, прежнее ТЗ первой очереди и предоставленный `planet_colony_sprites_refined_512.zip`. Архив находится среди загруженных пользователем материалов рабочей среды; сами PNG не встроены в `internal/server/web` и не входят в EXE.

Все 11 файлов — отдельные RGBA PNG 512×512 с прозрачным фоном:

| Файлы | Назначение |
|---|---|
| habitat.png | Жилой модуль локальной колонии |
| solar_panel.png | Солнечная электростанция локальной сцены |
| cargo_container.png | Контейнер / объект хранения |
| technical_node.png | Технический узел |
| tree.png, bush.png, grass_tuft.png | Отдельные растения локального сектора |
| rock.png, ore_outcrop.png | Камень и обнажение руды |
| mine_entrance.png | Вход в шахту |
| colonist.png | Персонаж; это один ракурс, не полный набор ходьбы |

В репозитории присутствуют SVG-голограммы космических объектов (`internal/server/web/object-*.svg`) и кораблей, эскизы кораблей PNG и архив контекста. Это не текстуры грунта, воды или берегов. `docs/design/planet-colony/spec-0.12.0.md`, раздел графики, явно разрешал простые заливки без текстур; текущий вид — осознанная первая очередь, а не сломанная загрузка PNG.

Спрайты из архива рисованные, предметные, с наклонным видом сверху. Они подходят для будущего локального режима после проверки масштаба, опорных точек и анимаций. Они не бесшовны и не предназначены для покрытия глобальной карты. Если размножить tree.png по всем шестиугольникам, получится иллюстрация деревьев размером с географический регион; если растянуть rock.png как грунт — появятся повторяющиеся контуры и прозрачные пустоты. Поэтому этот набор не подключён к обзорной карте.

## Выбранный способ

Гибридная система: каноническая процедурная география + процедурные маски + необязательные бесшовные микротекстуры. Сейчас сохранённые высоты, вода и русла создают один непрерывный географический растр; поверх накладывается гексагональная сетка и владения. В 0.12.4 добавлено освещение рельефа по градиенту тех же высот. Изображение рельефа кешируется на клиенте для открытой поверхности, а не пересоздаётся при каждом кадре или выборе сектора.

Берега, русла, озёра, геометрия гексов, границы владений и маски переходов остаются программными. PNG «готовый берег слева/справа» и готовая плитка реки не нужны: такие изображения не гарантируют совпадение с соседними секторами. Рисованные объекты и будущие постройки будут использоваться в локальной сцене, а не в качестве фона целого региона.

## Недостающие материалы для дизайнера

Все поверхности — строго ортографический вид сверху, без горизонта, перспективного уклона, больших объектов и текста. Цветовая гамма приглушённая, естественная, согласованная с текущими спрайтами; без магического свечения. Не запекать сильный направленный свет и чёрные тени: освещение будет вычисляться движком. Деталь должна работать после уменьшения до 128–256 px.

| Ресурс | Размер | Формат / прозрачность | Бесшовность | Использование |
|---|---|---|---|---|
| ground_grass | 512×512 | PNG RGB, полностью непрозрачный | Обязательна по X/Y | Низкоконтрастная основа травянистой почвы; без отдельных деревьев |
| ground_dry | 512×512 | PNG RGB | Обязательна по X/Y | Сухая земля с мелкой неоднородностью, без крупных трещин-композиций |
| ground_sand | 512×512 | PNG RGB | Обязательна по X/Y | Песок; мелкая зернистость, без встроенных берегов и волн |
| ground_rock | 512×512 | PNG RGB | Обязательна по X/Y | Обнажённая каменистая почва; без отдельной крупной скалы |
| ground_snow | 512×512 | PNG RGB | Обязательна по X/Y | Снег и наст, без жёсткой границы снежного поля |
| ground_volcanic | 512×512 | PNG RGB | Обязательна по X/Y | Тёмная вулканическая почва; без светящихся рек лавы и магических прожилок |
| water_detail (необязательно) | 256×256 | PNG RGB с нейтральной яркостью | Обязательна по X/Y | Очень слабая рябь; оттенок и глубина задаются географическим рендерером |
| vegetation_detail_01…03 | 256×256 | PNG RGBA; прозрачный край без ореола | Не требуется | Мелкие видимые сверху пятна растительности, без высотной перспективы; необязательны для первой интеграции |

У каждого файла — одна функция, без рамки, подписи, цветовой плашки и внешней тени. Сохранить исходники отдельно; экспорт PNG без потерь. WebP можно получить при интеграции и проверке качества, генератор изображений не должен переименовывать JPEG в PNG.

## Совмещение

- Текстуры повторяются в единых координатах **всей планеты**, не начинают узор заново на каждом гексе.
- Доли материалов, вода и суша задаются программными масками, вычисленными из сохранённой географии. Изображение не определяет наличие воды, залежей или возможности колонизации.
- Трава, грунт, песок и камень смешиваются масками; текстуры не содержат нарисованных переходов между биомами.
- Маски берегов и рек согласованы с будущим секторным сервером через общие координаты, seed и версию географии. Нельзя визуально спрятать действующий водный проход случайным спрайтом.
- На сильном уменьшении микродеталь приглушается; подписи и границы должны читаться лучше текстур. Нужны проверки повторения 3×3, уменьшения, совпадения противоположных краёв и отсутствия тёмных швов.
- Загружать материалы только при входе в планетарный режим, повторно использовать кеш. Не загружать PNG-набор локальной сцены при входе в космический терминал.

Для полноценного локального режима дополнительно потребуются направления и кадры движения colonist, согласованные опорные точки спрайтов и масштабы построек. Это отдельная очередь; нынешний комплект не объявляется готовым анимационным атласом.
