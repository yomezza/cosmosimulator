# Движение на поверхности · P2-5 / 0.19.0

Добавлены перемещение персонажа по клику, серверный поиск пути, коллизии, камера и масштаб. Используется существующая сохранённая сцена; её рельеф, природные объекты и координаты площадок не перегенерируются.

[Отчёт и проверки](REPORT.ru.md) · [Включение высадки и права PostgreSQL](../P2-4/README.ru.md) · [Общий план](../P2-0/PLAN.ru.md).

## Обновление

1. Остановить обе службы и сохранить резервную копию игровой схемы PostgreSQL.
2. Запустить **cosmosimulator 0.19.0**: cosmic runner применит `schema190.sql`, marker совместимости станет **5**. География, версии scene snapshot и экономические данные сохраняются.
3. Запустить **cosmosimulator-planet 0.19.0**. Права БД от P2-4 достаточны; новых GRANT не требуется. Сохраняются `PLANET_ENABLED=true`, внутренняя связь и Origin из инструкции P2-4.

Ready-ответ planet содержит `stage=P2-5`, `gameplay_ready=true` для собственного персонажа и `multiplayer_ready=false` для будущего присутствия других игроков.

Windows-сборки находятся в downloads и GitHub Release; предыдущие EXE сохранены. Не смешивать версии служб. Старый planet с marker=5 станет incompatible. Для отката — остановленные службы, согласованная резервная копия и соответствующие EXE.

## Управление

После обычной высадки на доступную площадку:

- **ЛКМ** выбирает клетку назначения. Её центр — точная цель маршрута; заблокированная клетка отклоняется, автоматического переноса цели на ближайшую сушу нет.
- **Колесо** меняет масштаб относительно курсора. Кнопки **− / +** также меняют масштаб.
- **Зажатая ПКМ** перемещает камеру для обзора.
- **К персонажу** возвращает слежение камерой.
- **Весь сектор** показывает шестиугольник целиком.
- **Вернуться в космос** останавливает движение, сохраняет позицию и завершает визит. Корабль остаётся у планеты.

Жёлтая линия показывает оставшийся маршрут. Новая цель заменяет предыдущую. В воде, за пределами сектора или у непроходимого препятствия появляется пояснение. Для слишком сложного маршрута можно выбрать промежуточную точку ближе.

Закрытие окна/вкладки останавливает движение и сохраняет текущую безопасную позицию. Сам визит остаётся: **Колонии → Продолжить высадку**. При смене вкладки старый controller останавливается и сохраняет положение до запуска нового. При потере связи управление приостанавливается; доступны повторный вход и возврат.

## Настройки planet

| Переменная | По умолчанию | Диапазон |
|---|---|---|
| PLANET_MOVE_SPEED | 4 единицы/секунду | 1–12, конечное число |
| PLANET_PATH_BUDGET | 24000 раскрытых узлов | 1000–65536 |

Настройки читаются из окружения **планетарной** службы при запуске. Ни масштаб камеры, ни частота кликов, ни скорость браузерного рендера не меняют физическую скорость. Общие параметры DB/lease/cache сохраняются.

## Текущие границы этапа

Показывается собственный персонаж. Видимость других персонажей/presence и полный stream относятся к P2-6, переходы между секторами — к P2-7. Художественная анимация, атлас ходьбы и окончательная графика — P2-8. Нет WASD, рубки, добычи, персонажного инвентаря или строительства.

Позиции рассчитываются в RAM и сохраняются контрольными точками, а не SQL на каждый кадр. При crash может потеряться часть движения после последнего успешного сохранения; полная нагрузочная/аварийная проверка будет в P2-9. Нативный SCM Windows в облачной Linux-среде не проверен; обе Windows x64 сборки кросс-компилированы.
