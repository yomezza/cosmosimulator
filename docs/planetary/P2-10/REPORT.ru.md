# P2-10 · документация и выпуск 0.23.0

Дата: 31 октября 2026. Документация второй очереди сведена в актуальный набор для двух служб. Изменения кода, измерения и функциональные проверки описаны в [P2-9](../P2-9/REPORT.ru.md).

Подготовлены единая инструкция PowerShell/SCM, параметры окружения и gateway, полный GRANT ограниченной роли, владельцы изменяемых данных, HTTP/WS-контракты с новыми полями, backup/rollout/rollback и действия после отказа. Добавлен общий [вход в документацию](../README.ru.md), прежние отчёты сохранены как история.

Windows x64 сборки текущего выпуска:

- `downloads/cosmosimulator-v0.23.0-windows-amd64.exe`;
- `downloads/cosmosimulator-planet-v0.23.0-windows-amd64.exe`.

Они собираются из одного состояния исходников с `CGO_ENABLED=0`, `-buildvcs=false -trimpath -ldflags='-s -w'`. Контрольные суммы — `downloads/SHA256SUMS`; GitHub Release содержит оба файла и manifest. Все предыдущие версии сохранены. Публикация идёт существующим tag workflow, который сначала проверяет manifest.

Новых SQL-таблиц/миграций нет, marker остаётся 7. Только для чтения planet metrics ограниченному логину добавляется `SELECT(role)`; пароль/кошелёк и права изменения cosmic данных не выдаются. Разделение на `platform/postgres`, чистые terrain/scene/pathing и самостоятельный `planetserver` сохранено; агрегатные измерения выделены в общий `platform/telemetry`.

Окончательная художественная приёмка preview-пака остаётся открытой. Нативные Windows SCM и нагрузка Windows требуют проверки на целевом хосте; Linux-проверки и кросс-компиляция не выдаются за такой запуск. Длительный soak и предел максимальной мощности сервера не устанавливались. Функции следующей очереди — рюкзак, добыча/строительство/хозяйство персонажем — этим выпуском не включены.
