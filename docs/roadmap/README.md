## Сквозные решения

- Название **«Корпорации-основатели»** одобрено для исходных крупных организаций мира. «Академия Эдема» остаётся стартовой корпорацией для новичков; не приравнивать её автоматически к основателям.
- Разведданные создаются исследованиями игроков. Игра не выставляет их изначально на продажу. Продажа и покупка проходят через станции; нельзя сохранить старую идею автоматически наполненных NPC-пакетов как источник таких данных.
- Название игры пока не выбрано. Эдем — название галактики, а не утверждённое окончательное название всей игры.
- Сохраняются русский и английский интерфейсы, пользовательские названия организаций и объектов не переводятся автоматически.
- При выпуске обновления исходники синхронизируются с GitHub; все версионные Windows-сборки сохраняются в `downloads`, создаётся GitHub Release. Эти документы сами по себе не являются выпуском.
