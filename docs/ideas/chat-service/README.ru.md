### Важные ограничения текущего Cosmosimulator

- Сейчас Cosmic уже имеет сессии и единственную company_id на игрока; Chat не дублирует их.
- Текущий Planet (P2-3 / 0.17.0 на момент изучения) не поддерживает реальный активный игровой визит. Поэтому Planet/Sector chat требуют future authoritative visit+sector fence; до его реализации эти два раздела выключены, но Global/Private/Corporation/Избранное могут работать.
- Существующий company_dissolve удаляет компанию сразу; до включения Corporation chat потребуется durable удаление с подтверждением физической очистки Chat.
- Game-admin role существует, назначенный game moderator и chat.moderate permission требуют расширения Cosmic.
- Если Cosmic Service недоступна, не работает весь Chat; если Planet Service недоступна, не работают только Planet/Sector.

### Правило handoff

Кодекс реализует утверждённое поведение, а не меняет игровую механику. Технические параметры, явно помеченные как предварительные/configurable, допустимо улучшать по тестам. Любое изменение продуктового правила сначала согласуется с владельцем и фиксируется отдельным MD, исходные утверждённые документы не перезаписываются незаметно.
