# Результат M0 — контракты перед рефакторингом

29 октября 2026. Исходная версия игры — 0.12.5.

## Выполнено

- Добавлены 16 браузерных сценариев поддерживаемого поведения и 5 проверок требований к известным дефектам. Проверяются реальные исходные файлы интерфейса, API полностью подменены синтетическими DTO.
- Для каждого теста создаются отдельные browser context, loopback HTTP server, storage и журнал запросов. Внешние URL и неожиданные мутации не отправляются. После теста ресурсы закрываются; неожиданные ошибки проваливают проверку даже у сценария с TODO.
- Пять дефектов имеют TODO только на вложенном требовании; их воспроизведение не означает исправления. Неожиданное выполнение требования проваливает запуск и требует перевести его в обычный регрессионный тест.
- Добавлены Go-проверки 12 anonymous API-входов без подключения к БД и 11 вариантов embedded delivery/MIME/CSP.
- Добавлен CI workflow с отдельными browser/Go jobs, dev-only package/lockfile и инструкция запуска с чистого checkout.
- Перенесены исходные реестры компонентов, настроек и повторяющихся решений, план миграции и рекомендации разработчику. Сохранены две просмотренные контрольные иллюстрации интерфейса на синтетических данных.
- Зафиксированы владельцы данных будущих двух служб и ограничения повторного использования DB-кода. Подключение pool не должно автоматически запускать migration/seed/simulation; `openDatabase` пока совмещает эти обязанности и не предназначен для прямого импорта второй службой.

## Результаты проверок

- `npm ci --ignore-scripts --no-audit --no-fund` — успешен; зависимости зафиксированы lockfile.
- `npm test` с установленным Chromium — 16 поддерживаемых сценариев прошли, 5 диагностических сценариев воспроизвели известные дефекты. С учётом вложенных TODO вывод Node: **26 tests, 21 pass, 0 fail, 5 todo**. Пять parent PASS относятся к корректной диагностике, а не к выполнению требований TODO.
- `env -u TEST_DATABASE_URL go test ./... -count=1 -v` — **20 верхнеуровневых PASS, 55 SKIP**, ошибок нет.
- `go vet ./...` — успешен, диагностик нет.
- Игровой JS/HTML/CSS/SQL, handlers, `database.go`, `go.mod` и `go.sum` не изменены. Новые Go-файлы являются только `_test.go`.

PostgreSQL integration не запускалась: выделенная одноразовая БД не предоставлена в этой среде. Инструкция безопасного запуска есть в tests/ui; 55 SKIP не выдаются за покрытие экономики и конкурентных операций. Проверка полномочий авторизованного игрока остаётся в существующих DB-тестах, а не доказывается browser fixtures.

## Следующий этап

M1: RequestScope/session boundary, пилот Users и проверки позднего ответа, закрытия окна, смены аккаунта/роли и поиска A/B. На M0 production-исправления этих дефектов не выполнялись. Новая версия Windows-службы не выпускается для тестовой инфраструктуры: игровая версия остаётся 0.12.5.

Откат — удаление добавленных тестов/workflow/docs; данные и пользовательские preferences не мигрируют. По принятому поэтапному порядку после отчёта M0 работа останавливается до отдельной команды на следующий этап.
